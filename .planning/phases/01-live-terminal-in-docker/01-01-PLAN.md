## Phase Goal

ROADMAP Goal (verbatim): One `docker run` opens a dark trading terminal on :8000 that shows the 10 default tickers with streaming prices, $10k cash, and a connection status dot that survives a network drop.

Note: this Goal is not in user-story format (`user-story.validate` fails). The planner did not invent a story. Run `/gsd-mvp-phase 1` to set one before `/gsd-verify-work`.
